## 2. Stages actually run, in order

1. Scan intake → `G/mesh-manifest.json` (hash, counts, bbox, watertight=false, units MEASUREMENT_VERIFIED, scale 1.0, `derived: []`).
2. (Failed earlier candidate) → a 27-tooth / Ø21.75 mm candidate existed and was invalidated by operator measurements (`G/DESIGN_NOTES.md:5`). Its artefacts are not in the repo.
3. Operator measurement spec → `G/OPERATOR_SPEC.json` (tooth counts, ODs, widths, bore; bound to the scan by `source_stl_sha256`, identical to `G/mesh-manifest.json#sha256`).
4. Parametric build + designer self-check → `M02-02-03_CORRECTED.step` (later delivered as `G/M02-02-03_WATERTIGHT_SOLID.step`, same sha256: `G/model_params.json#step_path`, `G/qa_report.json#expected_frozen_sha256`, `G/SHA256SUMS.txt:2`) and `G/model_params.json` (`G/model.py:85-102`).
5. Freeze STEP by sha256 → `G/qa_report.json#hash_before_qa`.
6. Independent QA on the frozen STEP (OCP re-import, BRepCheck, analytic faces, 0.01 mm re-tessellation + trimesh topology, section-based tooth counting at 3 stations/gear, twist, axial extents) → `G/qa_report.json`, `G/VERDICT.md`.
7. Visual review (3 renders from STEP-retessellated STL, pixel census + manual) → `G/qa_step_*.png`, `G/visual_review.json`.
8. Target validator (expected-value checks) → `G/target_validator_report.json`.
9. Reproducibility rebuild (re-run source, compare volume/bbox) → `G/reproducibility_report.json`.
10. Hash re-check after QA → `G/qa_report.json#hash_after_qa`, `#hash_unchanged_during_qa: true`.

The order of stages 7–9 relative to each other is not recorded.

## 6. Feature tree

As built in `G/model.py` (names from `G/model_params.json#feature_chain`):

1. `BIG_INVOLUTE_TOOTH_SKETCH` — `tooth_face(BIG)` (`G/model.py:36-55`): polygonal involute, one tooth: radial line from `attach = rf − 0.04` to base circle, `FLANK_SAMPLES=20` points per flank from rb to ra, `TIP_SAMPLES=7` points on the tip arc, closed with `Wire.make_polygon` → `Face`. Params: `COMMON_MODULE`, `PRESSURE_ANGLE_DEG`, `BIG.teeth`, `BIG.tip_diameter`.
2. `BIG_EXTRUDE` — `Solid.extrude(..., Vector(0,0,width))` at `z0=0`, width 3.0 (`G/model.py:60`).
3. `CIRCULAR_PATTERN_30X` — root cylinder core `Cylinder(r_root, width)` then loop fusing the tooth rotated `phase_deg + i·360/teeth` (`G/model.py:59-64`), `.clean()`.
4. `SMALL_INVOLUTE_TOOTH_SKETCH` — same function with `SMALL` (teeth 17, tip Ø11.2).
5. `SMALL_EXTRUDE` — width 6.95 at `z0=3.0`.
6. `CIRCULAR_PATTERN_17X` — same loop.
7. `CONTINUOUS_CORE_UNION` — `bridge = Cylinder(min_root=4.35, total=9.95)` fused with both gears "to create positive-volume connectivity across the coplanar axial transition" (`G/model.py:76-81`).
8. `THROUGH_BORE_CUT` — `Cylinder(BORE_DIAMETER/2, total+2)` cut, `.clean()` (`G/model.py:82-83`).
9. Export STEP + STL (`tolerance=0.01, angular_tolerance=0.05`), re-import, self-check (BRep valid, 1 solid, 1 shell, closed, volume>0) and raise on failure (`G/model.py:86-101`).

No fillets or chamfers. The "circular pattern" is realised as an explicit fuse loop of rotated copies, not `PolarLocations`.

Resulting B-Rep (inspection only, text grep of the STEP file, not a recorded gate): 2354 `ADVANCED_FACE`, 2306 `PLANE`, 48 `CYLINDRICAL_SURFACE`, 0 B-spline. The 48 cylinders match `G/qa_report.json#analytic_cylindrical_faces` (30 × Ø16.5 root segments, 17 × Ø8.7, 1 × Ø1.95 bore). The involute flanks are therefore planar facets.

## 12. Lessons

1. When operator measurements (tooth count, OD, widths, bore) are available, they override scan-derived candidates; an earlier 27T/Ø21.75 candidate was wrong and replaced. — `G/DESIGN_NOTES.md:5`, `G/OPERATOR_SPEC.json` — from a failure.
2. Bind the operator spec to the scan by hash (`source_stl_sha256`) so measurements cannot drift to another mesh. — `G/OPERATOR_SPEC.json#source_stl_sha256`, `G/mesh-manifest.json#sha256` — success.
3. Model a gear as one involute tooth + circular pattern on a root-circle core, with module/PA/tooth count/tip Ø as named parameters; let measured OD set the tip (truncation) rather than forcing nominal addendum. — `G/model.py:29-64`, `G/README.md:25` — success.
4. Explicitly list every gear parameter not measured (module, PA, phase, backlash, profile shift, root fillet, hub) as an assumption rather than inventing geometry. — `G/README.md:21-27` — success/limitation.
5. For coplanar stacked bodies, add a continuous core bridge to guarantee single-solid connectivity. — `G/model.py:76-81` — success.
6.
